# LMS Course Board

Live public course deadlines and lecturer announcements board auto-synced from Hermes LMS.

- **Live Site**: https://7adel32.github.io/lms-deadlines/
- **Views**: Switch between **Deadlines** and **Announcements** from the title pull-down menu (`Course [Deadlines ▾]`).
- **Privacy**: Publishes only sanitized course names, instructors, titles, due dates, and course-wide announcements — never submission statuses, grades, private messages, authenticated LMS URLs, or student identifiers.
- **Retention**: Shows all upcoming deadlines plus past-due deadlines for up to 5 days, and all current-term lecturer announcements sorted newest first.
