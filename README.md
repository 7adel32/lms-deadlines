# LMS Deadlines

Live public course deadlines board auto-synced from Hermes LMS.

- **Live Site**: https://7adel32.github.io/lms-deadlines/
- **Privacy**: Publishes only sanitized course names, instructors, titles, and due dates — never submission statuses, grades, or student identifiers.
- **Retention**: Shows all upcoming deadlines plus past-due deadlines for up to 5 days.
